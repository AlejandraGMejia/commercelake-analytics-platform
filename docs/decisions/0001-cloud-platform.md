# ADR-0001: Google Cloud Platform

Status: Proposed

## Context

The project requires hands-on experience with
cloud-based analytical data platforms.

## Decision

Prioritize Google Cloud Platform with BigQuery
and Cloud Storage.

## Rationale

- Managed analytical warehouse
- Integration with dbt
- Industry-relevant cloud experience
- Support for SQL-based analytics

## Constraints

- Prioritize free usage where eligible
- Review current pricing before deployment
- Avoid unnecessary always-on resources
- Configure billing alerts
- Document cleanup procedures

## Consequences

Cloud deployment is deferred until costs,
permissions, and quotas are reviewed.
